Understand the GST Calculator

A simple explanation of what the numbers mean and how this estimate is built.

Base amount?GST-inclusive amount?

1. What this calculator does

This either adds GST to a base price or removes GST from an inclusive price. Use it for invoices, quotations, and quick price checks.

2. How the calculation works

  1. In Add GST mode, multiply the base amount by the GST rate %.
  2. Add that GST amount to the base amount for the final amount.
  3. In Remove GST mode, divide the inclusive amount by 1 plus the GST rate.
  4. Subtract the calculated base from the inclusive amount to find GST.

3. Worked example

  1. Base amount: ₹10,000 with an 18% GST rate.
  2. GST is ₹10,000 × 18% = ₹1,800.
  3. Final amount is ₹10,000 + ₹1,800 = ₹11,800.
  4. Removing 18% GST from ₹11,800 returns a ₹10,000 base and ₹1,800 GST.

Result: Add and Remove modes give opposite views of the same transaction.

4. Common mistakes

  • Subtracting 18% directly from a GST-inclusive amount.
  • Using the wrong GST rate for the supply.
  • Confusing base amount with final amount.
  • Using this calculator to decide CGST, SGST, or IGST treatment without checking place-of-supply rules.
